Configuration du fournisseur de portefeuille
Enveloppez votre application avec les composants WalletProvider et WalletModalProvider pour gérer le contexte du portefeuille et l'interface utilisateur :

import React, { FC, useMemo } from "react";
import { WalletProvider } from "@demox-labs/aleo-wallet-adapter-react";
import { WalletModalProvider } from "@demox-labs/aleo-wallet-adapter-reactui";
import { LeoWalletAdapter } from "@demox-labs/aleo-wallet-adapter-leo";
import {
  DecryptPermission,
  WalletAdapterNetwork,
} from "@demox-labs/aleo-wallet-adapter-base";
import "@demox-labs/aleo-wallet-adapter-reactui/styles.css";

export const Wallet: FC = ({ children }) => {
  const wallets = useMemo(
    () => [
      new LeoWalletAdapter({
        appName: "MonAppAleo",
      }),
    ],
    []
  );

  return (
    <WalletProvider
      wallets={wallets}
      decryptPermission={DecryptPermission.UponRequest}
      network={WalletAdapterNetwork.Localnet}
      autoConnect
    >
      <WalletModalProvider>{children}</WalletModalProvider>
    </WalletProvider>
  );
};

🧠 4. Utilisation du hook useWallet
Le hook useWallet fournit l'accès au contexte du portefeuille :

import { useWallet } from "@demox-labs/aleo-wallet-adapter-react";

const { wallet, publicKey, connected, connect, disconnect } = useWallet();
✍️ 5. Signature de messages
Pour signer un message avec le portefeuille connecté :

import { WalletNotConnectedError } from "@demox-labs/aleo-wallet-adapter-base";
import { useWallet } from "@demox-labs/aleo-wallet-adapter-react";
import { LeoWalletAdapter } from "@demox-labs/aleo-wallet-adapter-leo";
import React, { FC, useCallback } from "react";

export const SignMessage: FC = () => {
  const { wallet, publicKey } = useWallet();

  const onClick = useCallback(async () => {
    if (!publicKey) throw new WalletNotConnectedError();

    const message = "Un message à signer";
    const bytes = new TextEncoder().encode(message);
    const signatureBytes = await (
      wallet?.adapter as LeoWalletAdapter
    ).signMessage(bytes);
    const signature = new TextDecoder().decode(signatureBytes);
    alert("Message signé : " + signature);
  }, [wallet, publicKey]);

  return (
    <button onClick={onClick} disabled={!publicKey}>
      Signer le message
    </button>
  );
};
🔐 6. Déchiffrement de messages
Pour déchiffrer un message chiffré :

import { WalletNotConnectedError } from "@demox-labs/aleo-wallet-adapter-base";
import { useWallet } from "@demox-labs/aleo-wallet-adapter-react";
import React, { FC, useCallback } from "react";

export const DecryptMessage: FC = () => {
  const { publicKey, decrypt } = useWallet();

  const onClick = useCallback(async () => {
    const cipherText = "texte_chiffré";
    if (!publicKey) throw new WalletNotConnectedError();
    if (decrypt) {
      const decryptedPayload = await decrypt(cipherText);
      alert("Message déchiffré : " + decryptedPayload);
    }
  }, [publicKey, decrypt]);

  return (
    <button onClick={onClick} disabled={!publicKey}>
      Déchiffrer le message
    </button>
  );
};
📄 7. Requête de transactions et déploiement de programmes
Pour demander des transactions ou déployer des programmes, vous pouvez utiliser les méthodes appropriées fournies par le portefeuille. Assurez-vous que le portefeuille est connecté et que vous avez les autorisations nécessaires.

🧪 8. Réseau de test
Pour le développement, vous pouvez utiliser le réseau de test (Localnet ou TestnetBeta). Assurez-vous de configurer le paramètre network en conséquence dans le WalletProvider.
