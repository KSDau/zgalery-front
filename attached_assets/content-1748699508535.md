###### High scalability


snarkVM takes computation off-chain and only requires provers to publish proof of computation on-chain, offering greater scalability.

- ![](<Base64-Image-Removed>)

###### Unlimited runtime


Secure, off-chain computation negates the gas-reliant execution model, providing unlimited application runtime.

- ![](<Base64-Image-Removed>)

###### Absolute decentralization


snarkOS creates a fully decentralized and public ecosystem for transaction verification and state storage.

- ![](<Base64-Image-Removed>)

###### Increased data security


Users can share a zero-knowledge proof instead of their personal information, which reduces the amount of sensitive data you need to store and secure.
